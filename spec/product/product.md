# Product Spec — ShukBot (Помощник АСОИУ)

## Проблема

Студенты и преподаватели, работающие с материалами по АСОИУ, тратят много времени на поиск точных определений, формулировок и правил в разрозненных учебных материалах.

Обычный поиск по ключевым словам (Ctrl+F) не даёт прямого ответа на вопрос — нужно перечитывать десятки страниц лекций, методичек и курсовых работ. При этом использование публичных нейросетей (ChatGPT и аналоги) для учебных целей рискованно: они могут выдумать определение, которого нет в программе курса, или использовать некорректную терминологию.

## Решение

**ShukBot** — веб-приложение, которое работает как «умный поисковик» по **студенческой базе знаний по архитектуре АСОИУ**.

Программа находит в загруженных лекциях или курсовых абзацы, в которых встречаются слова из вопроса (поиск BM25), отправляет этот текст нейросети и просит её сформулировать понятный человеческий ответ. Сам поиск работает по совпадению слов, а смысл вопроса учитывает нейросеть — но только в пределах найденных фрагментов.

**Главный принцип:** нейросеть выступает только как «переводчик» с языка документов на простой язык. Она **строго ограничена** текстами АСОИУ и не имеет права добавлять информацию извне. Если ответа в базе нет — система честно об этом скажет.

## Целевая аудитория

| Сегмент | Потребность | Как ShukBot помогает |
| :--- | :--- | :--- |
| **Студенты АСОИУ** | Быстро найти определение термина или формулу для подготовки к экзамену/курсовой. | Вводят вопрос («Что такое АСОИУ?»), получают готовый ответ строго по лекциям. |
| **Преподаватели** | Проверить, что студенты используют корректные формулировки из учебной программы. | Быстро находят точные цитаты из методичек для проверки работ. |

**Основной пользователь (MVP):** Студент, который готовится к зачёту по АСОИУ и хочет быстро уточнить формулировку, не перечитывая всю лекцию.

## Ключевые функции (MVP)

Продукт должен уметь:

1. **Принимать вопрос** на естественном языке через веб-интерфейс.
2. **Искать** релевантные фрагменты в загруженной базе документов по АСОИУ (лекции, методички, курсовые).
3. **Формировать ответ** с помощью нейросети на основе найденных фрагментов.
4. **Указывать источники** (из какого документа и страницы взята информация).
5. **Честно отказывать**, если в базе АСОИУ нет информации по вопросу (вместо того чтобы выдумывать).
