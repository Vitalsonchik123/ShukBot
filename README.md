# ShukBot — умный поисковик по документам
ШукБот - ваш профессиональный помощник в изучении АСОИУ

ShukBot — веб-приложение, которое отвечает на вопросы пользователя строго на основе загруженной базы документов (лекции, курсовые, методички). Система находит релевантные фрагменты, передаёт их нейросети и выдаёт понятный ответ со ссылками на источники.

## Как это работает

1. Пользователь задаёт вопрос в веб-интерфейсе.
2. Приложение ищет подходящие абзацы в базе документов с помощью алгоритма BM25.
3. Найденные фрагменты «склеиваются» с вопросом и отправляются нейросети.
4. Нейросеть формирует ответ, опираясь только на эти фрагменты.
